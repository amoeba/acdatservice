# Temporary private area-pack publisher

`scripts/area_pack_upload_worker.mjs` is a **separate, trusted, temporary** Cloudflare Worker for bulk uploading content-addressed area packs to R2. It does not modify the public `acdatservice` Worker, its routes, Rust code, or its `wrangler.toml`. The public service continues to read the same `world/area-packs/` objects. This utility is not a public ingest API: possession of the bearer key grants list/read/create access to this prefix. The binding's bucket is shared with production, so a mistake in deployment, binding, access controls, or credential handling can expose or corrupt data. Use one publisher per release and remove it immediately after verification.

## Operator-only lifecycle (not automated by this repo)

1. Review and merge the utility and run `npm test`. Confirm the intended client catalog, local filenames, decoded lengths/hashes, disk space, and upload plan. Never publish a partial release catalog. Use a single publisher/writer per release; do not race publishers or reuse a failed release without reconciling its objects.
2. Provision a **new** 64-hex-character random `UPLOAD_KEY` as a Worker secret, scoped to this short-lived deployment only. Do not put it in the repo, shell history, command arguments, logs, CI output, screenshots, or the public Worker. Restrict deployment access, Worker routes, and the R2 binding to the intended bucket. The secret is bearer authorization, not a signed URL or a per-object capability; the Worker itself limits keys to `world/area-packs/`.
3. Deploy **separately** with a temporary Wrangler configuration outside the tracked production config. Its `main` must be the **absolute path** to `scripts/area_pack_upload_worker.mjs`, with an `EXTRACTED_BUCKET` R2 binding to the intended extracted bucket, a compatible Workers runtime with `FixedLengthStream` and `DecompressionStream`, and the `UPLOAD_KEY` Worker secret. Do not reuse `wrangler.toml`, deploy to the public custom domain, or replace the production Worker. Do not enable public observability with request/authorization logging. Restrict access to the temporary endpoint as an additional layer where possible. The account uses **Workers Free**: do not set a custom `cpu_ms` limit (unsupported on Free), assume a paid CPU allowance, or upgrade the plan as part of this workflow. If secret provisioning requires a first deployment, deploy privately and set the secret before sending any requests; the Worker returns 401 until the secret is present.
4. A trusted client sends `Authorization: Bearer <UPLOAD_KEY>` on **every** request, including list and read; use HTTPS. Never print the header or key. List `GET /objects` (optional `?cursor=<opaque cursor>`) until `truncated` is false. The fixed prefix and limit are `world/area-packs/` and 1000. Responses are JSON `{objects:[{key,size,etag}],truncated,cursor}` (cursor is null at the end). Read `GET /objects/area-<64 lowercase hex>.bin[.br]` to check existing bytes. The `.br` suffix is an opaque object name here: reads return stored bytes with `application/octet-stream`, length, and **no** `Content-Encoding`. Compare hashes/lengths against the trusted local manifest before skipping an existing object.
5. Upload to `PUT /objects/<filename>` with a known `Content-Length` (wire bytes), `X-Area-Pack-Bytes` (decoded byte length, 1–256 MiB), and `X-Area-Pack-Transfer: identity` or `gzip`. For `identity`, both lengths must match; this is the default for objects **larger than 2 MiB** and goes directly through the native `FixedLengthStream` without JavaScript per-chunk transforms. Use `gzip` by default only for objects **at most 2 MiB decoded** on Workers Free: larger gzip transfers can exceed the Free CPU budget and return 503 even after retries. For `gzip`, send a gzip-compressed transfer body, **without HTTP `Content-Encoding`**; the Worker decompresses it into an exact-length stream before putting the decoded bytes into R2. This works for both `.bin` and `.bin.br`: to publish precompressed Brotli, gzip the *Brotli file* for transport, then set `X-Area-Pack-Bytes` to the Brotli file's size. Larger `.br` objects should use identity transfer of their already-Brotli-compressed file. The object is stored with octet-stream metadata and immutable cache-control. Check `201` for newly created, `412` for already existing (verify that object's content, never assume a match), `400` for invalid input, `401` for invalid/missing auth, `404` for absent object/unknown route, and `500` for R2/runtime failures. Every response is `Cache-Control: no-store`; do not cache private listing or reads.
6. Upload both representations as necessary, verify catalog-wide completeness and sizes/hashes via read/list, then check public delivery with `scripts/check_area_pack_delivery.mjs` before announcing a release. A failed or interrupted upload leaves successfully created objects intact; conditional writes never overwrite an existing object. Repair only missing objects after reconciling existing ones. Never use the public service as an upload endpoint.
7. **Tear down immediately**: delete the temporary Worker, remove its route and R2 binding, revoke/delete its secret and any temporary deployment credentials, and verify the endpoint is unreachable. No cleanup operation deletes R2 objects; removing the Worker does not roll back published packs. Do not leave a long-lived bulk-writer capability online.

The Worker never deletes objects, never overwrites a key (R2 atomic `if-none-match: *` conditional put), and never accepts arbitrary prefixes or filenames. The bearer key is compared in a fixed-length loop; malformed/missing credentials return 401 before any R2 operation. Do not rely on a preflight GET for write safety: only the conditional `put` resolves concurrent writers. Large identity transfers stream directly from the request body through a native `FixedLengthStream` with backpressure and exact-length enforcement, not through JavaScript counting transforms or a full-body buffer. Gzip transfers retain the wire/decoded byte counters. A failed conditional put cancels the producer so it cannot hang on a stalled stream. There is no CORS grant or secret logging.
